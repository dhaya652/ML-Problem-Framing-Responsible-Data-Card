Customer Churn Prediction

ML Problem Framing & Responsible Data Card

A responsible approach to evaluating machine learning for real-world customer decisions.

About This Project

This project explores whether machine learning is justified for predicting customer churn. It documents the decision, data quality, risks, evaluation metrics and non-ML baseline before model training.

Project Deliverables

01. Problem Framing Memo

Decision definition, prediction target, baseline and evaluation metrics.

View Memo

02. Responsible Data Card

Data provenance, consent, privacy, missingness and leakage risks.

View Data Card

03. Risk Register

False positives, false negatives, fairness and rollback controls.

View Risk Register

04. Baseline Notebook

Python-based dataset exploration and non-ML baseline evaluation.

View Notebook

Conclusion

The supplied dataset is too small for reliable production machine learning. A transparent baseline and additional responsible data validation are recommended before deployment.
