Important limitation:
The supplied CSV contains only 12 rows (5 churned, 7 not churned), and no timestamps,
data provenance, consent information, or churn-horizon definition. The work therefore
recommends NO-GO for production ML and treats the baseline as a classroom demonstration.
The supplied HTML file is a RabTech Academy internship webpage, not a responsible-data-card
template, so a fresh data card was created from the assignment requirements.
